# kipp•punkt

> From **Kipppunkt** (German: *tipping point*).

Software engineering is going through a paradigm shift. A brutal one. Many developers haven't even noticed yet. The ones who have are sitting in a terminal, chatting with an AI, watching it type. They think that's the revolution.

It's not.

We build upon decades of battle-tested practices. Requirements engineering, feedback loops, CI. None of that needs to be replaced.

What changed is the middle. The part between "here's what I want" and "here's a PR for you to review." That part is now automatable. Fully. No TUI or IDE. No pair-programming with a chatbot.

That's what kipp•punkt does. Requirements go in. Features come out. You stay with the tools you already trust.

## Projects

- [`@kipppunkt/build`](https://github.com/kipppunkt/build) - Autonomous AI coding workflow with human-in-the-loop via GitHub PRs: takes your features → implements → opens PRs → responds to reviews → repeats. 24/7. You review & merge. From anywhere 🏝️
- `@kipppunkt/refine` (TBA) - Your AI-powered sparring partner for spec refinement. Turns rough ideas into actionable requirements. Right inside GitHub issues. Pairs with `@kipppunkt/build`.
